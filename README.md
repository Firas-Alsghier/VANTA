# VANTA

> **Built for your everyday.**

VANTA is a modern fashion and footwear e-commerce project built with Nuxt and Vue.

The project focuses on clean design, practical functionality, and a smooth shopping experience. It is also a personal development project designed to strengthen frontend and backend development skills through building a real application from scratch.

## Tech Stack

### Frontend

- Nuxt
- Vue
- JavaScript
- Composition API
- CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose

### Tools & Libraries

- VueUse
- Lucide Vue Next
- ESLint
- Prettier

## Features

- Modern fashion-focused homepage
- Men's collection
- Women's collection

- Product details
- Product filtering
- Shopping cart
- Checkout
- User authentication
- User account

## Main Pages

- `/` — Home
- `/men` — Men's collection
- `/women` — Women's collection
- `/accessories` — Accessories
- `/products/[slug]` — Product details
- `/cart` — Shopping cart
- `/checkout` — Checkout
- `/auth/login` — Login
- `/auth/signup` — Sign up
- `/account` — User account
- `/account/orders` — Order history

## Design

VANTA follows a minimal and premium fashion aesthetic.

### Design Principles

- Clean and modern
- Strong typography
- Generous whitespace
- High-quality product imagery
- Minimal borders and shadows
- Subtle animations
- Responsive layouts
- Simple and intuitive navigation

### Color Direction

- Near-black
- Deep charcoal
- Warm off-white
- Soft gray
- Black typography
- Muted neutral accents

Bright colors, excessive gradients, glassmorphism, and unnecessary visual effects are intentionally avoided.

## Development Goals

This project is not only about creating an e-commerce website.

The main goals are to:

- Improve JavaScript fundamentals
- Strengthen Vue and Nuxt skills
- Practice component architecture
- Understand state management
- Practice API development
- Work with MongoDB and Mongoose
- Implement authentication
- Build real-world CRUD functionality
- Improve frontend and backend integration
- Write code independently and understand the decisions behind it
